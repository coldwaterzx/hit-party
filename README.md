用 Three.js 做，LoL 式 3D 斜俯視鏡頭。不需要安裝任何東西，音效全部即時合成。

## 怎麼開

1. 雙擊 `start.bat`。
   - 它會用 Python 開一個本機伺服器（`http://localhost:8780/`），並自動開啟瀏覽器。
   - 這個伺服器會關掉瀏覽器快取，改了程式重新整理就會生效。
   - 第一次開需要網路，從 CDN 載入 Three.js。
2. 主選單上方的分頁選類別（大亂鬥／合作／足球／曲棍球／小遊戲／測試場），選好選項後按模式卡片開始；下方可以切換 1／2 人、道具、地圖機關、音量。按 Enter 直接開始目前分頁的第一個模式。
3. 建議接 Xbox 或 PS 手把，用 Chrome 玩。

> 不能直接雙擊 `index.html` 開啟，瀏覽器會擋下本機的 JS 模組，一定要透過伺服器。
>
> 這裡用 8780 埠，原本的打擊遊戲用 8770，兩個可以同時開。

## 操作

| 動作 | 手把 | 鍵盤滑鼠 |
|---|---|---|
| 移動 | 左搖桿 | WASD |
| 揮錘：點一下＝秒揮，按住＝蓄力 | X（RB、RT 也可以） | J 或滑鼠左鍵 |
| 瞄準 | 蓄力時用左搖桿轉向；也可以用右搖桿 | 滑鼠 |
| 翻滾（前 0.15 秒無敵） | B（LB 也可以） | 空白鍵 |
| 暫停 | – | Esc，或右下角按鈕（切到別的視窗也會自動暫停） |
| 重置場地（練習模式） | Start | R |
| 開關停頓／震動／音效／K.O.／閃白 | – | 1–5 |
| 隱藏介面（截圖用；測試場是隱藏兩邊面板） | – | H |
| 拉遠／拉近鏡頭（高爾夫） | – | 滑鼠滾輪 |

**本機雙人**：主選單下方「玩家」選 2 人。2P 用方向鍵移動、`/` 或 Numpad1 揮錘、`.` 或 Numpad2 或右 Shift 翻滾；接了兩支手把的話，第 2 支是 2P。2P 在對戰類模式是對手，在合作、足球、曲棍球 2 打 2 是隊友。

## 停車場撞球大亂鬥（v0.6.0）

### 撞球物理

| 項目 | 說明 |
|---|---|
| 滑行 | 蓄力揮不再是「飛一段固定距離」，而是給一個初速讓它在地上滑，摩擦力把它慢慢停下。初速＝√(2 × 減速 × 擊退距離)，所以地上箭頭的長度還是準的（Lv1／Lv2／Lv3＝4／8／14 m） |
| 庫邊反彈 | 撞到超市門面、左側矮牆、柱子、停著的車，會照入射角反彈繼續滑（保留 75% 速度）。撞得夠用力（垂直牆面 11 m/s 以上）就是壁咚，停下來後會暈眩 |
| 撞球連鎖 | 滑行中撞到任何東西（小怪、AI 對手、你自己）都會沿連心線交換動量：輕的撞重的會彈回來，重的撞輕的會把它撞飛。被撞走的東西也會繼續撞別人 |
| 袋口 | 場上有 5 個黃黑框的黑洞（左上角、上方中間、右上角、左側中間、左下角）。滑行中的東西經過就會掉進去；走路經過不會掉 |
| 出界 | 右側和下方的平台邊緣跟以前一樣，滑出去就掉到街上 |
| 翻滾 | 翻滾的無敵時間內，滑過來的東西會直接穿過你 |

### 得分

| 怎麼得分 | 分數 |
|---|---|
| 把小怪打出平台 | 小兵 1、投擲兵 2、胖墩 3、金色小兵 5 |
| 打進袋口 | 上面的分數 × 2 |
| 先撞牆再進袋（庫邊球） | 再 +1 |
| 把 AI 對手打出場（出界或進袋） | +3 |
| 自己被打出場 | −2（不會扣到負的），3 秒後重生，重生後 1.5 秒無敵 |

- 分數算給**最後打到它的人**：你打的小怪撞到別隻、把別隻撞進袋口，也算你的。8 秒內有效。
- 金色小兵每 25 秒出現一隻，看到人就逃。

### AI 對手

AI 跟玩家用同一套操作（移動、秒揮、蓄力、翻滾），只是指令由程式產生：

- 每 0.4 秒評估一次：場上每個小怪（還有對手）往每個袋口和平台邊緣打，哪一個「分數 ÷ 走過去和蓄力的時間」最高，路線上沒有障礙物擋住。
- 走到目標後面的「母球位置」，邊走邊蓄力到需要的段數，對準後放開。瞄準有隨機誤差（預設 ±6°）。
- 看到東西快滑過來，或有人對著自己蓄力到 Lv2 以上，會翻滾閃避（預設 50% 機率）。
- 旁邊有人在蓄力時，會用秒揮把對方挑起來打斷。
- AI 蓄力時，地上的箭頭用它自己的顏色顯示，你可以看出它要打哪裡，提早翻滾躲開。

### 模式

| 模式 | 說明 |
|---|---|
| 對戰 | 你＋3 個 AI（主選單可以選 1～5 個），3 分鐘比分數 |
| 最後存活 | 每人 3 條命，被打出場少一條，命用完就淘汰。剩最後一個人（或你被淘汰）就結束，照淘汰順序排名。名牌上的愛心是剩下的命 |
| 搶寶 | 場上只有一顆金蛋，走過去碰到就拿起來。拿著的人每秒 +1 分、移動變慢；被打到（挑起、打飛、暈眩）就掉蛋。3 分鐘比分數 |
| 足球 | 2 打 2 或 3 打 3；勝利條件可以選 3 分鐘或先進 3 球 |
| 練習 | 沒有對手、不限時，有兩個木樁 |
| 守超市 | 合作。小怪一波一波從平台邊緣爬上來衝向超市自動門（紅圈），摸到門就扣門的耐久（20），歸零就輸。每清完一波選一個全隊強化（巨錘、快速蓄力、強力擊退、修門、援軍、道具雨）；每 5 波來一隻胖墩王，會震地 |
| Boss 戰 | 合作，在撞球桌上。胖墩王平常幾乎打不動，會震地、會朝人衝刺；衝刺撞到庫邊會暈 3.5 秒，這時候大家一起把它打進袋口。要進袋 3 次才贏，全隊共用 10 條命 |
| 護送購物車 | 合作，在停車場。把很重的購物車推到收銀台（綠圈），走路推或用錘子打都可以。小怪會繞到車前面把車往外推；車掉出平台或進袋口就弄丟了。送到 3 台贏，弄丟 3 台輸 |
| 接力挑戰 | 合作，用主選單選的地圖。還在飛的東西被另一個隊友接著打，就是接力 ×2、×3…，得分＝基本分 × 接力數（進袋再 ×2）。90 秒比團隊總分，20／45／80 分各一顆星。AI 隊友會把小怪挑起來給你接 |
| 桌上曲棍球 | 1 打 1 或 2 打 2，先得 7 分的贏（可選 3／5／7）。四周都是擋板，只有兩端中間的球門口要守；每隊只能待在自己那半邊。冰球幾乎不減速、撞擋板反彈。**走路撞到冰球就能把它撞出去**（越快撞越遠），揮錘打冰球時方向會自動往對方球門修正，移動速度是平常的 1.35 倍（AI 慢一點）。進球後冰球發給失分的那一邊 |
| 保齡球 | 小遊戲。5 格，每格 2 球，站在紅線後面把球打向 10 支球瓶。全倒（STRIKE）＋10、補中（SPARE）＋5。球滑進兩邊溝槽就是洗溝 |
| 冰壺 | 小遊戲。6 顆冰壺，在紅線前打出去，停下來看離大本營中心多近：中心圈 3、白圈 2、藍圈 1 分。冰面很滑，冰壺會互撞，可以把前面的推進去 |

### 高爾夫

主選單「高爾夫」分頁。**大家同時開打、各打各的球**，沒有輪流，比誰先把自己的球打進洞。

- **打球**：走到自己的球旁邊揮錘。按住越久打越遠（不分段，地上箭頭就是會滑多遠，最遠 22 m），點一下是 1.2 m 的短推桿。球太快（超過 9 m/s）會滑過洞口。
- **干擾**：別人的球也打得動，可以把它打偏、打下水；也可以直接打人。只有打自己的球才算桿。
- **罰桿**：球掉進水裡或掉出球場罰 1 桿、回到上一個停下的位置（最後一下是別人打的就不罰）。
- **一洞的結束**：所有人都進洞；或第一個人進洞後再過 30 秒；或 150 秒到。打到 Par＋6 桿會封頂。沒進洞的人記 `max(桿數, Par)＋2`（不超過封頂）。
- **畫面**：右上角排名表（桿數、進洞順序）和小地圖（每個人的球、球洞）；滾輪拉遠鏡頭看路線。

| 選項 | 影響 |
|---|---|
| 球場 | 派對球場（9 洞）、入門球場（5 洞，原本的迷你高爾夫）、匯入的球場 |
| 打幾洞 | 前 3 洞或全部 |
| AI 對手 | 0～3 個 |
| 計分 | 比總桿數（少的贏），或比完成順序（每洞第 1、2、3 名拿 5／3／2 分，其他有進洞的拿 1 分；多的贏，同分比桿數） |

### 測試場

像格鬥遊戲的訓練模式，主選單「測試場」分頁進入。預設在「訓練室」：格線地板（1 m 一格），起點到 Lv1／Lv2／Lv3 距離線上各站一個木樁；左、上、下是軟墊牆，右邊是開放邊緣，另有柱子、彈跳柱、袋口各一個。也可以切換到任何一張地圖測。

| 區塊 | 內容 |
|---|---|
| 左邊工具列 | 生成（木樁、小兵、胖墩、投擲兵、金色小兵、道具箱、足球、冰球、高爾夫球、母球、購物車、胖墩王，出現在你面前 3 m）；AI 對手（加一個、全部移除、沙包模式＝站著不動）；11 種道具直接拿；時間 0.1×／0.25×／0.5×／1×、凍結、下一格；顯示判定範圍（白＝秒揮、黃＝蓄力揮）、地面指示器、K.O. 特寫、地圖機關；切換場地；重置木樁、清空 |
| 右邊調整面板 | 分 9 類（手感、判定與擊退、撞球物理、打擊回饋、效果開關、鏡頭、AI、對戰規則、其他模式），可以搜尋。改過的參數會變黃色、旁邊有 ↺ 還原。下方：這一類還原、匯出 JSON、匯入、全部還原。右上角 ⟩ 可以收合 |
| 下方擊退量測 | 最近 6 次擊退：段數、誰打誰、初速、預計距離、實際滑行距離（出界或進袋也會標出來）、撞牆次數和最大撞牆速度、打擊停頓幀數，以及 FPS |

快捷鍵：F 凍結、N 下一格、T 切換時間倍率、R 重置木樁、H 隱藏兩邊面板；1–5 開關打擊停頓／震動／音效／K.O.／閃白。

### 道具

道具箱是場上的「?」箱子，用錘子打破（或用打飛的東西撞破）就拿到，馬上生效，效果大約 8 秒。身上的效果會顯示在頭上的名牌。AI 也會去搶道具箱。

| 類型 | 道具 | 效果 |
|---|---|---|
| 改錘子 | 巨錘 | 判定範圍 ×1.4、擊退距離 ×1.5，人也變大 |
| | 連發錘 | 蓄力門檻 ×0.45，很快就能打 Lv3 |
| | 磁力錘 | 蓄力時把 5.5 m 內的東西吸到面前，放開一起打飛 |
| 改物理 | 彈力球化 | 被你打到的東西撞牆完全不減速、摩擦力剩 35%，在場上亂彈 |
| | 重量化 | 質量 ×4、被打只飛 35%；走路撞到人會把人撞飛 |
| | 冰面 | 全場摩擦力剩 30%，場地蓋上一層冰 |
| 陷阱 | 香蕉皮 | 在身後和場上各丟一個，別人踩到會往前滑出去 |
| | 地雷錐 | 在面前放一個三角錐，有東西碰到就爆炸，把 3.4 m 內全部炸飛 |
| | 臨時袋口 | 在面前 4 m 開一個洞，8 秒後關閉（足球不會出現） |
| 保命 | 護盾 | 擋掉一次打擊，打你的人反被彈開 |
| | 錨 | 被打只飛 15%，也挑不起來 |

所有陷阱、爆炸、撞飛的得分都算給放陷阱（或用道具）的人。

## 這份基底包含什麼

| 項目 | 說明 |
|---|---|
| 秒揮 | 點一下，前方半圓內的敵人被往上打飛 |
| 3 段蓄力 | 按住，錘頭和地上箭頭的顏色依序變白→黃→紅；箭頭長度就是滑行距離（4／8／14 m） |
| 浮空追擊 | 秒揮把敵人打到空中，馬上蓄力再打一次，擊退距離 ×1.3 |
| 壁咚、出界 | 打到超市門面、左側矮牆、柱子或停著的車會反彈，用力撞是壁咚；打出停車場平台（右側、下方有黃黑警示條）會掉到街上，跟你有關的擊落會觸發黑白慢動作 K.O. 特寫 |
| 撞球 | 滑行中的東西撞到別人，會照質量和角度把動量傳過去 |
| 重量 | 胖墩（紅色大隻）擊退距離 ×0.4，互撞時質量是小兵的 3 倍 |
| 反彈 | 用蓄力揮把投擲兵（藍色）丟來的球打回去 |
| 打擊回饋 | 打擊停頓、震動、閃白、殘影、粒子、合成音效；得分時跳分數。AI 之間的打擊停頓和震動會減弱，畫面才不會一直卡 |
| 參數面板 | 在測試場右邊，分 9 類、可以搜尋；每一項都可以即時調整、單項還原，自動存在瀏覽器裡，也可以匯出／匯入 JSON |

### 和原本 v0.1.0 不一樣的地方

打擊遊戲後來在 v0.1.1–v0.1.7 調過一些節奏，也修過一些錯。和玩法無關的部分都一起帶過來了：

- **節奏比較快**
  - 秒揮冷卻 0.45 → 0.25 秒。
  - 蓄力門檻 Lv2 0.7 → 0.55 秒，Lv3 1.3 → 1.0 秒。
  - 揮完硬直 0.6 → 0.32 秒。
- **輸入緩衝 0.25 秒**：冷卻還沒好就先按，冷卻一好就會自動出手，不會吃掉按鍵。
- **滑行時間上限 2.8 秒**：被連鎖撞飛的東西不會一直滑。
- **暫停功能**：可以暫停，也可以關掉音效。
- **修正**
  - 在面板輸入文字時，不會誤觸快捷鍵。
  - 移除角色時會釋放模型記憶體。
